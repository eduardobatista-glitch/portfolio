## 🚀 Como Hospedar no GitHub Pages

Este portfólio foi desenvolvido em HTML5/CSS3/JavaScript estático, garantindo carregamento instantâneo e total compatibilidade com o **GitHub Pages**.

### Passo a Passo:

1. **Fazer o Push dos Arquivos:**
   ```bash
   git init
   git add .
   git commit -m "feat: portfolio acadêmico eduardo batista"
   git branch -M main
   git remote add origin https://github.com/eduardobatista-glitch/<nome-do-repositorio>.git
   git push -u origin main
   ```

2. **Ativar o GitHub Pages:**
   - Acesse o repositório no GitHub.
   - Vá em **Settings** > **Pages** (no menu lateral esquerdo).
   - Em **Build and deployment** > **Source**, escolha `Deploy from a branch`.
   - Selecione a branch `main` e a pasta `/ (root)`.
   - Clique em **Save**. Em 1 ou 2 minutos seu portfólio estará online!
